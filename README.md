# sri-test-repo

A lightweight team repository for experimenting, testing workflows, and sharing reusable scripts.

---

## Setup

- **Install dependencies:**
  ```bash
  npm install
  ```
- **Run the app:**
  ```bash
  npm start
  ```

---

## Usage

Run the main script with a target environment:

```bash
node index.js --env production
```

---

## Project Structure

- `index.js` — Application entry point
- `package.json` — Project metadata and dependencies
- `src/` — Core source files
- `tests/` — Unit and integration tests
- `README.md` — Project documentation
